# Game Shooter (SFML)

Аркадный 2D шутер на **C++ + SFML**: управляй кораблём, уклоняйся от астероидов, набирай очки и следи за количеством жизней.

## Управление

- **Enter** — начать игру (из стартового экрана)
- **Стрелки / A-D / W-S** — движение корабля 
- **Space** — выстрел

---

## Что реализовано

- Стартовый экран *Press Enter to start*
- Игровая сцена со звездным фоном
- Игрок (корабль)
- Препятствия/враги (астероиды)
- Подсчет **Score**
- Система **Lives**
- Отрисовка HUD (очки/жизни)

---

## Сборка и запуск

### Visual Studio (Windows)
1. Установи SFML (или подключи через vcpkg).
2. Открой проект в Visual Studio.
3. Укажи пути к `include/` и `lib/` SFML.
4. Скопируй нужные `*.dll` SFML рядом с `exe` (или добавь в PATH).
5. Собери и запусти.
